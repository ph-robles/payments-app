🎨 Web Design do Zero — Explicação para Crianças (e Adultos que estão começando!)
Imagina que você vai construir uma casa. Antes de colocar as paredes, você precisa de um plano, né? Web design é a mesma coisa — só que no lugar de uma casa, você está construindo um site.
Vamos por partes!

Mas calma! Como web designer, você não precisa saber programar. Existem ferramentas que fazem isso por você — como o Figma e o Framer. É como usar o Word em vez de escrever código de máquina.
🖍️ PARTE 2 — Os 5 Princípios de Design (a base de tudo)
Antes de abrir qualquer ferramenta, você precisa entender esses 5 princípios. Todo site bonito do mundo segue eles.
1️⃣ Espaçamento — "Deixe as coisas respirarem"
Olha dois exemplos:
❌ Ruim:
Código
✅ Bom:
Código
Sabe quando sua mochila está tão cheia que você nem acha nada? Site lotado é igual. Espaço em branco não é desperdício — é elegância.
2️⃣ Hierarquia Visual — "O mais importante aparece primeiro"
Imagine um jornal. O título é gigante, o subtítulo é médio, o texto é pequeno. Isso é hierarquia.
No site você faz igual:
Título principal → letra grande e grossa
Subtítulo → letra média
Texto normal → letra pequena
Botão → cor chamativa
O olho da pessoa vai naturalmente do maior pro menor. Você controla onde ela olha.
3️⃣ Cores — "Use no máximo 3"
Sites profissionais usam no máximo 3 cores:
1 cor principal (a mais usada, ex: azul)
1 cor de destaque (para botões, ex: laranja)
1 cor neutra (fundo ou texto, ex: branco ou preto)
Quer saber quais cores combinam? Acesse coolors.co — ele gera paletas prontas de graça.
4️⃣ Tipografia — "A fonte certa muda tudo"
Fonte é o estilo das letras. Olha a diferença:
Comic Sans → parece trabalho escolar de 1999
Montserrat → parece marca moderna e profissional
Regra simples:
Use 1 fonte para títulos (mais grossa/expressiva)
Use 1 fonte para texto (mais simples, fácil de ler)
Fontes gratuitas e bonitas: Google Fonts (fonts.google.com)
5️⃣ Alinhamento — "Tudo no lugar certo"
Nunca deixe elementos jogados aleatoriamente. Tudo alinha com alguma coisa.
Centralizado, à esquerda ou à direita — mas sempre consistente. Sabe quando uma foto está levemente torta na parede? Incomoda, né? Site desalinhado causa a mesma sensação.

🏠 PARTE 4 — Criando sua primeira tela no Figma
Vamos criar juntos a tela inicial (chamada de Hero) de um site fictício. Siga cada passo:
Passo 1 — Criar a tela
Aperte F no teclado
No painel direito, escolha "Desktop" → 1440 x 1024
Clique na área branca — apareceu um retângulo cinza. Essa é sua tela!
Passo 2 — Fundo colorido
Clique na tela
No painel direito, em Fill, clique na cor e mude para #1A1A2E (azul escuro bonito)
Passo 3 — Título principal
Aperte T, clique na tela e escreva: "Aprenda Design do Zero"
Selecione o texto, mude o tamanho para 64 e a cor para branco
Passo 4 — Subtítulo
Aperte T de novo, escreva: "Transforme sua criatividade em renda"
Tamanho 24, cor cinza claro (#AAAAAA)
Passo 5 — Botão
Aperte R, desenhe um retângulo
Cor: #E94560 (vermelho/rosa vibrante)
Arredonde os cantos: no painel direito, em Corner radius, coloque 12
Aperte T, escreva "Começar agora", cor branca, coloque em cima do retângulo
Resultado: você acabou de criar seu primeiro Hero de site! 🎉
🎓 PARTE 5 — O que estudar e em que ordem
Agora que você entende o básico, aqui está a ordem exata de aprendizado:
Semana 1 e 2 — Fundamentos
[ ] Criar conta no Figma
[ ] Assistir: "Figma para iniciantes" no YouTube (canal Origamid)
[ ] Praticar os 5 princípios recriando telas de apps que você usa
Semana 3 e 4 — Design de verdade
[ ] Aprender sobre grid (a grade invisível que organiza tudo)
[ ] Aprender componentes no Figma (criar um botão e reusar em vários lugares)
[ ] Recriar a página inicial de um site famoso (ex: Spotify, Nubank)
Semana 5 e 6 — Publicar na internet
[ ] Criar conta no Framer (framer.com)
[ ] Pegar seu design do Figma e montar no Framer
[ ] Publicar — você terá um site real com link para mostrar
Semana 7 e 8 — Portfólio e primeiros clientes
[ ] Criar conta no Behance (behance.net)
[ ] Postar seus 3 melhores projetos (podem ser fictícios)
[ ] Criar perfil no Workana e candidatar em 5 projetos
💡 Dica de ouro
Não espere aprender tudo para começar a fazer. A melhor forma de aprender design é copiar sites que você acha bonito dentro do Figma. Não para vender — só para treinar o olho e a mão.
Todo designer profissional começou assim.
